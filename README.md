# Nordic Stations Explorer

Interactive map of the climate stations of the Nordicana D network (Centre d'études
nordiques) in Quebec and Nunavut, companion to the data papers of the network. Each
station opens its metadata: position, elevation, variables, record period, permafrost
zone, climate class, biome and its Nordicana D dataset.

Backgrounds: satellite imagery, terrain (hillshade), OpenStreetMap. Overlays: land
cover (ESA WorldCover 2021, around the sites), permafrost zones (Obu et al., 2019),
Köppen–Geiger classes 1991–2020 (Beck et al., 2023), biomes (RESOLVE 2017). Sources
and licences are listed on the page.

A site can be linked directly: `index.html#Bylot%20Island`.

## Files

- `index.html` - the page (Leaflet 1.9.4, no build step)
- `data/` - stations and overlays, generated by `build.py`

`build.py` runs in the source repository, where the station metadata and the
quality-controlled series live; this repository is a copy of its `explorer/` folder.

## Run locally

```bash
python -m http.server -d . 8000   # then open http://localhost:8000
```
